## 정의와 비교 범위

- 절편과시장·규모·가치요인을포함한36개월OLS. 종목초과수익=alpha+beta요인+epsilon으로적합하며alpha를잔차점수에더하지않는다. 최근1개월제외11개월epsilon평균/표준편차(ddof1).
- lag1은투자월t의회귀를t-1까지,lag2는t-2까지계산한다.두방식의점수형성기간은t-12~t-2로같다.최신공표본과공표지연가정이며당시자료빈티지/정확한공표일미검증이다.
- 원아카이브36개월이완전하면그이력사용.부족하면Yahoo조정월가격36개월이완전하고같은과거회귀창안아카이브중첩12개월이상·수익차중앙값0.1%p이하/p95 1%p이하인경우에만Yahoo전체창을사용한다.창안에서두원천월수익을짜깁기하지않고결측을0으로채우지않는다.
- 아카이브전용공통기간은2002-02~2026-10 297개월이다. 보충계산은이력과중첩조건워밍업을고려해2000-02부터사용한다.공통2002기간도comparison.csv에별도저장했다.
- 교집합재정렬대조는동일후보·동일이력·동일3~8위를고정한다.전체잔차6종은동일이력전체12-1상위6과대조한다.모든설정의SPY12M·멀티4·시장중지시현금0은동일하다.
- 반반병행·현금25%는단독잔차결과확인뒤사후추가한진단이다.병행은매월중복종목비중을합산한순거래액으로비용계산,최대12종목이다.비중그리드최적화는없다.

## 재현

운영data에덮어쓰지말고입력커밋의utils·archive_usa·data/snowball/monthly를별도사본으로펼쳐commit.txt에입력SHA를기록한다.원가격개별캐시가없으면압축가격묶음에서복원할수있다:

```python
from pathlib import Path
import pandas as pd
out = Path('기록/2026-11-10-USA500-잔차모멘텀')
(out/'monthly_prices').mkdir(exist_ok=True)
for ticker, frame in pd.read_csv(out/'downloaded_monthly_prices.csv.gz').groupby('ticker'):
    frame.drop(columns=['ticker', 'month']).to_csv(out/'monthly_prices'/f'{ticker}.csv', index=False)
```

CSV재직렬화는원문바이트해시를바꿀수있으나같은수치입력이다.원문SHA는수집당시개별원문추적용이다.공식요인원문은저장파일그대로사용한다.가격을새로받으면원천의과거수정/티커이력변경으로결과가바뀔수있다.

```powershell
python 기록/검토/usa500_residual_review_20261110.py --snapshot <별도사본> --output 기록/2026-11-10-USA500-잔차모멘텀
python 기록/검토/usa500_residual_verify_20261110.py --output 기록/2026-11-10-USA500-잔차모멘텀
```

재수집은 usa500_residual_download_20261110.py를사용한다.요청제한발생시재확인은대기후--retry-rate-limited로1초이상간격을두며제한지속시중단한다.영구빈조회에반복요청하지않는다.
