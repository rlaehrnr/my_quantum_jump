# 한국 스노우볼 현금 조건 검산 자료

저장소 루트에서 실행:

```powershell
python 기록/검토/korean_snowball_cash_20261013.py
```

- 재현 입력 커밋: `bf900221c45606795538b9b568d192aa9bb5fda9`. 이후 로봇 갱신 데이터로 실행하면 수치가 달라질 수 있다.
- 2026-09까지만 계산하며 로컬 CSV만 사용한다. 제품 코드·data·라이브 전략을 수정하지 않는다.
- 기존 방어 모드이며 가용 방어 후보 점수가 모두 엄격히 0 미만일 때만 현금100으로 바꾼다.
- 현금 이자 0%, 매수 목표비중 증가분에 비용 0.25%, 매도비용 0%. 재진입 비용은 다시 계산한다.
- `결과.json`: 전체·연속·2022년 이후·방어 후보 점수 완비 이후 지표, 비용 민감도, 연간 수익, 현금월, 초기 누락월, 입력 가격 지문.
- `*-월별.csv`: 같은 보유월에 대한 기존/현금안 종목·비중·총수익·비용·순수익. `all_negative`는 후보 점수 조건, `cash`는 방어 모드 조건까지 충족한 실제 전환이다.
- 연환산 수익률은 최종자산배수^(12/개월수)-1. 월말 MDD는 최초자산 1을 포함한 최고점 대비 하락률이다.
- `continuous`는 기존 엔진의 초기 누락월 이후 연속 구간. 다른 부분기간도 연속 운용의 월수익을 잘라 시작자산을 1로 재설정하며, 구간 시작에 강제 최초매수비용을 추가하지 않는다.
- 기존 525개월 총수익·비용·순수익과 라이브 엔진을 대조하고 방어 점수를 명시적 창 계산으로 검산한다. 현금안 비용은 벡터화 목표비중 차감으로 재검증한다.
- 표본을 재사용한 비교이며 월중 낙폭·세금·호가·슬리피지·실제 비중표류는 모델링하지 않는다.
- 해석·판정은 `기록/DGbrain-이관대기.md`의 2026-10-13 한국 스노우볼 항목에 있다.
