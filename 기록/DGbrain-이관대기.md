# DGbrain 이관 대기

**작업장이 쌓고, 편입은 DGbrain 세션이 한다** (DGbrain `CLAUDE.md` §워크플로우).
여기 있는 항목은 아직 위키에 안 들어갔다. 편입이 끝나면 해당 절을 지운다 — **지우는 것도 DGbrain 세션이 한다.**

DGbrain 세션에서 이 파일을 열고, 아래 항목을 위키 규칙(40줄·frontmatter·위키링크)에 맞춰 편입한다.

## 여기 쌓는 규칙 (2026-08-18 사용자 지시)

- **백테스트를 돌렸으면 결과가 나온 그 턴에 바로 적는다.** 말해줄 때까지 기다리지 않는다
- **채택·기각·보류 전부.** 코드를 하나도 안 바꾼 검토도 넣는다
- **다듬느라 미루지 않는다.** DGbrain이 **일요일**에 가져가므로 그 전까지 얼마든지 고칠 수 있다.
  틀린 게 보이면 해당 절을 고치면 된다 — 안 넣는 것보다 설익은 채로 넣는 게 낫다
- 항목마다 **편입 대상 페이지**를 적는다. `백테스트-기록.md` 번호는 **그 페이지를 열어 확인**한다.
  병렬 세션이 같은 번호를 집은 적이 실제로 있다 (아래 또 메리츠 건: 8번 → 10번으로 정정)

### 맘 비과세 공격 상위 4종 vs 5종 재비교 (2026-10-05)

- **편입 대상:** `wiki/quant/백테스트-기록.md` **15번 예정** · `wiki/quant/맘-비과세-글로벌-듀얼모멘텀.md`. DGbrain 기록의 마지막 번호 13과 이 대기함의 14를 확인해 15로 잡았다. 실제 편입 때 병렬 추가 여부를 다시 확인한다.
- **질문:** 현재 공격 상위 5종(모두 통과하면 각 20%)을 4종(모두 통과하면 각 25%)으로 바꿀 근거가 있는가.
- **고정 조건:** `35b8d904063e0cb7597eea7cf0c465d44614c386`의 로컬 로봇 CSV만 사용, 2026-09 확정월까지. 공격 10종·12M 상대/절대 모멘텀·음수 제외 후 균등 재분배, TIP/VWO/VEA/VIXY cond1, 방어 6종의 3M MA 이격도 상위 2종은 그대로. 라이브 `compute_signals_mamtax`·`run_backtest_mamtax`를 캐시 없이 호출하고 `MAMTAX_TOP_OFF`만 프로세스 메모리에서 4/5로 바꿨다. 제품 코드·data 파일은 수정하지 않았다.
- **기간 일치:** 원래 시작월은 4종 2016-11, 5종 2017-04. 비교는 **2017-04~2026-09, 114개월**로 맞췄다. 두 안 모두 2017-03 말 현금에서 시작해 최초 매수비용 0.25%를 동일하게 반영. 이후 새로 매수하는 목표 비중에만 비용 0.25% 적용. 투자월 이전 월말 신호를 다음 달 수익률에 적용. 두 안 모두 공격 102개월·방어 12개월이며 중간 누락월 없음.
- **공통기간 결과 (4종 / 5종):** CAGR **28.2996% / 28.3039%**, 누적수익 **966.9441% / 967.2824%**, MDD **-17.5386% / -12.3397%**, 연변동성 **17.2623% / 16.1881%**, Sharpe **1.5433 / 1.6348**, Sortino **3.0821 / 3.4357**, 최악월 **-15.4504%(2026-07) / -12.3397%(2026-03)**. 수익률 차이는 사실상 없고 5종의 최대낙폭은 5.1989%p 작았다.
- **현재 후보를 전부 비교할 수 있는 기간:** 공격 10종의 12M 점수가 모두 갖춰진 신호월은 2024-10부터, 실제 보유월 **2024-11~2026-09, 23개월**. CAGR **34.7098% / 37.9045%**, MDD **-17.5386% / -12.3397%**, Sharpe **1.2770 / 1.5097**, Sortino **2.2869 / 2.8845**. 후보가 모두 존재하던 최근 구간에서도 5종이 우세하나 표본이 짧고 별도 미사용 검증구간은 아니다. 구간 지표는 장기 운용 월수익을 잘라 자산곡선을 1로 다시 시작한 값으로, 구간 시작에 강제 전량 매수를 가정하지 않는다.
- **구간 의존성:** CAGR은 2017-04~2020-12 **33.01% / 34.02%**, 2021~2023 **17.80% / 16.72%**, 2024-01~2026-09 **34.06% / 34.05%**. 2026년 1~9월 실제 누적수익은 **18.22% / 25.32%**. 2024·2025 연간수익은 4종이 높았으므로 5종이 모든 구간에서 수익률로 우월한 것은 아니다.
- **한 달 의존성:** 2026-07 월수익을 두 안에서 똑같이 제거한 진단에서는 CAGR **30.90% / 30.23%**, MDD **-12.84% / -12.34%**, Sharpe **1.7447 / 1.7826**. 5종의 큰 낙폭 개선은 해당 급락에 상당히 의존한다. 실제 성과표가 아닌 민감도 진단이며 제거 뒤 전환비용은 재계산하지 않았다.
- **비용 민감도 (4종 / 5종 CAGR):** 0% **29.35% / 29.29%**, 0.1% **28.93% / 28.89%**, 0.25% **28.30% / 28.30%**, 0.5% **27.25% / 27.33%**, 1% **25.18% / 25.39%**. 5종의 MDD·Sharpe·Sortino 우세는 다섯 비용 설정에서 유지. 기본비용의 연평균 매수 목표비중 합계는 **3.36 / 3.14배**.
- **불확실성:** 월수익 차이는 4종 우세 41개월·5종 우세 31개월·동일 42개월, 대응 t=**0.2102**. 월별 짝을 유지한 원형 6개월 블록 부트스트랩 20,000회(seed=20261005)에서 4종/5종의 연환산 상대 복리 차이 95% 구간은 **-2.13%~+1.79%**. 수익 우열을 통계적으로 단정할 근거는 없다. 순위 선택수만 두 안으로 고정했으며 다른 파라미터를 탐색하지 않았다.
- **판정:** **상위 5종 유지.** 수익이 사실상 같은 장기 비교에서 위험 지표가 낫고, 최근 완비 후보 구간도 반대 증거가 없다. 4종으로 집중도를 높일 근거가 부족하다. 라이브·백테스트 공통 상수 `MAMTAX_TOP_OFF=5`는 이미 이 선택이므로 전략 코드 수정·매매 신호 변경 없음.
- **2026-09 신호(10월 운용) 차이:** 5종은 KODEX 200TR·은행고배당·TIGER 일본니케이225·KODEX 미국나스닥100·TIGER 미국S&P500 각 20%. 4종은 미국S&P500을 빼고 나머지 각 25%. 비교 목적으로 계산했으며 실제 주문은 하지 않았다.
- **해석 한계:** 로봇 CSV의 기존 가격·분배금 처리와 장수 ETF↔실운용 ETF 별칭을 그대로 썼다. 별도의 세금·실제 호가·슬리피지·분배금 현금흐름은 모델링하지 않았다. 비용은 직전 목표비중 대비 증가분 기준으로, 월중 가격 변화에 따른 비중 표류까지 재현한 실거래 비용은 아니다. MDD는 월말 기준이며 월중 낙폭은 더 클 수 있다. 현재 유니버스가 완비된 표본은 23개월뿐이므로 장기 CAGR 절대 수준을 현재 전략의 미래 기대수익으로 쓰지 않는다.

### KOSPI200 금 방어 6M 이분법 vs 6M·12M 삼분법 (2026-09-29)

- **편입 대상:** `wiki/quant/백테스트-기록.md` **14번** · `wiki/quant/my-quantum-jump-대시보드.md`
- **질문:** KOSPI200 방어 구간에서 현재 백테스트 기본값인 `금 6M 위=금100 / 아래=현금100`과, 화면 최종판단의 `6M 위=금100 / 6M~12M=금50·현금50 / 12M 아래=현금100` 중 어느 쪽이 나은가.
- **고정 조건:** 2014-02~2026-09, 152개월. KOSPI 6M 마켓타이밍, 하락 종목 1M·3M 각각 100개 이상 방어, 하락장 종료 뒤 금 1개월 연장, 퍼펙트 1~6위·달리는말 1~2위, 편도비용 0.25%. 투자월 직전 월말 금 가격으로 판단해 미래참조를 막았다. 금50 구간은 금 수익과 비용을 각각 절반 반영했다.
- **검산:** 동일 변환으로 6M 이분법을 재구성했을 때 현 엔진 월수익률과 최대오차 0.0.
- **대표 앙상블(50:50):** 6M 이분법 CAGR **68.27%**, MDD **-14.71%**, Sharpe **1.428**, Sortino **5.331**. 6M·12M 삼분법 CAGR **67.63%**, MDD **-14.71%**, Sharpe **1.417**, Sortino **5.368**. 삼분법은 CAGR -0.64%p, MDD 차이 없음.
- **전체 전략:** 6개 전략 모두 삼분법 CAGR이 0.58~0.69%p 낮았다. MDD는 5개 전략에서 같고, 퍼펙트만 삼분법이 -18.74%→-17.75%로 1.00%p 완화됐다.
- **표본:** 방어 85개월 중 금100 55개월·금50 9개월·현금100 21개월. 두 방식이 달라진 금50 9개월은 5승 4패, 삼분법의 해당 월 복리 **-4.35%**, 평균 -0.48%/월, 대응 t=-0.74로 유의하지 않다.
- **의존성:** 2026-06 금 급락(금100 -8.84%, 금50 -4.42%, 이분법 현금 0)이 전체 차이 대부분을 만들었다. 이 달을 빼면 삼분법 CAGR 열세는 -0.04%p, 2025-12까지만 봐도 -0.04%p로 사실상 동일하다.
- **판정:** **현재 6M 이분법 유지.** 삼분법이 위험을 일관되게 낮추지 못했고 규칙만 복잡해진다. 다만 차이가 발생한 표본이 9개월뿐이라 “6M이 우월”하다는 강한 결론이 아니라, **삼분법으로 바꿀 근거가 없다**는 결론이다. 화면 최종판단의 금50 표시는 백테스트 기본값과 불일치하므로 별도 정리 대상이다.
- **후속 적용:** 사용자 승인으로 KOSPI200 월별 상세·실시간 데일리의 방어 표시도 `6M 이상=금100 / 6M 아래=현금100`으로 통일했다. 백테스트 기본 규칙은 이미 6M 이분법이라 월수익률은 바뀌지 않았다.
- **한계:** 현금수익률 0%, 월별 완전 리밸런싱 비용 가정. 매우 높은 전략 CAGR 자체는 집중 모멘텀·표본기간 영향이 크므로 절대 수준보다 두 방식의 상대 차이만 해석한다.
